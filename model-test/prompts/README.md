# prompts/

- 1 ファイル 1 本。ファイル名（拡張子なし）が出力ファイル名と評価表の「プロンプト」列になる。
- **`nsfw.txt` は空のプレースホルダー。中身はユーザーが記入する**（無い・空のときは batch_run がスキップする）。公開リポジトリなので `.gitignore` で除外している。
- 登場人物はすべて明確な成人として書く。
- `_` で始まるファイルは部品:
  - `_cel_suffix.txt` … `--cel` を付けると各プロンプトの末尾に足す（セル風検証版。出力名は `<名前>_cel_<シード>.png`）
  - `_negative_sdxl.txt` … ネガティブ入力のあるワークフロー（SDXL / Anima）用。FLUX 系（CFG≒1）では使わない
