# ❄️ 橘 柊（たちばな ひいらぎ）

第4章「冬」の主人公。19歳の大学生でアイドル志望。異常な願望の果てに、公衆の面前で幼児退行する。

4人の中で**唯一、破綻が「自発」である**。他の3人が奪われるか事故に遭うのに対し、柊は自分の意思で降りていく。アイドルを目指すという表の顔と、女性の身体を消して子供に退行しようとする裏側が、同一人物の中に矛盾したまま同居している。

## 🎭 顔

| 項目 | 設定 |
| :--- | :--- |
| **動物モチーフ** | 🐇 **白うさぎ — か弱い小動物**。常に何かに怯えて身を縮め、抱き上げられることを待っている。**自分から走り出さない**ことがこの人物の本質 |
| **顔のモデル** | **當真あみ** |
| **髪色・質感** | **青みのある真っ黒**（ブルベ冬）。可憐で細い髪質 |
| **髪型** | ミディアムボブ |
| **輪郭** | **卵型。全体に曲線的**で、うさぎを思わせる繊細さ。線があまり太くない。**実年齢より幼く見える** |
| **眉** | **やや垂れ眉。全体に困ったような表情**をつくる。庇護欲をくすぐる主要因 |
| **目** | **大きく丸く、うるんだ瞳。黒目がち。瞳の色は4人中もっとも色素が薄いグレー**。元気さではなく、**神経質さと弱さ**を湛える。ただし楓よりは愛嬌がある |
| **鼻・口** | 小ぶりな鼻と口 |
| **肌** | **眩しいほどの白さ**。血の気が薄く、冬の静寂に溶け込むような儚さ |
| **コントラスト** | **4人中もっとも強い。**真っ黒な髪と青白い肌が最大の明度差をつくる |
| **赤面・生理表現** | 寒さの青白さと、恥辱でぽっと頬が上気する赤の対比 |

> [!tip] パーソナルカラーは「冬」— 白うさぎは、そもそも高コントラストの生き物
> 高コントラストと儚さは一見矛盾するが、**白うさぎは純白の毛と赤い目という最大級のコントラストを持つ**。モチーフとブルベ冬は矛盾しない。
>
> 儚さは低コントラストではなく、**顔立ちの小ささ**で出す。真っ黒な髪と青白い肌という強い画面の中に、小ぶりな鼻と口だけが頼りなく置かれる——**白い顔に、黒い髪と大きな目だけが浮いている**状態になる。人形的で、どこか不気味。
> これは「自分の意思で子供を演じる」という第4章の擬態と、そのまま同じ質感になる。

> [!warning] 髪色が黒系3人に増えた — 割るのは色み
> 桃香だけが明るい茶で、**向日葵・楓・柊の3人が黒系**になった。髪色が差別化から脱落しないよう、**色みで割る**。
>
> | | 髪の色み |
> | :--- | :--- |
> | 🌻 向日葵 | 青みを含んだ**ソフトなダークブラウン〜黒**（グレイッシュ） |
> | 🍁 楓 | **温かみのある深いブラウン**寄りの黒（オータムライトで濃いブラウンに転ぶ） |
> | ❄️ 柊 | **青みのある真っ黒**。3人中もっとも黒く、もっとも冷たい |
>
> 16色パレットでも階調を割り当てれば表現できる。**「3人とも黒髪」で済ませないこと。**

## 🦴 肉体

| 項目 | 設定 |
| :--- | :--- |
| **身長・等身** | 155cm / 6.5頭身。4人中最も小柄 |
| **体型** | **ふくよか。ただし身長が低く、4人中もっともメリハリがない。**全体が曲線的で、くびれらしいくびれを持たない**やや幼児体型**寄り |
| **質感** | **ムニムニしたぬいぐるみ感。**柔らかいというのは体型の話であって、線の細さのことではない |
| **胸** | サラシで潰しているため、**着衣時の輪郭は平坦**。脱げば柔らかく厚みがある |

> [!important] 「ふくよか」が向日葵と正反対の意味になる
> 向日葵と柊はどちらもふくよかだが、**向日葵はメリハリの最大値、柊はメリハリの最小値**。同じ語で正反対を指すため、**シルエットだけで完全に別人**になる。
> さらに向日葵は170cmで4人中最も高く、柊は155cmで最も低い。**豊かさの方向が真逆**に置かれている。

> [!note] サラシは「平坦に見せる」ための装置
> 実際の身体は柔らかく厚みがあるのに、着衣時は平坦。**本当の身体を隠して子供の輪郭を作る**という擬態が、下着の段階から始まっている。
> 脱いだときに現れる落差そのものが、第4章の主題になる。

| 部位 | 設定 |

> 他の3人が「着ているもの」でキャラクターを語るのに対し、柊は「着ていないもの」で語る。

## 📉 心理的軌道と崩壊プロセス

### 1. 【防寒】固く閉ざされた殻
厚手のマフラーとタイツで身を包み、外気の寒さと社会の視線から自分を過剰に守ろうとする。

### 2. 【屈服】炬燵の中の破綻
凍てつく自室、炬燵の中で身体のコントロールを失う。防寒具が脱ぎ捨てられ、むき出しの弱さが露出する。

### 3. 【擬態】子供への着地
児童の衣服を自ら選んで身につけ、子供を演じることで大人の責任から降りる。馬鹿馬鹿しい柄の子供用パンツが、かつての失禁の記憶と結びついた装置として機能していく。

> [!important] 桃香との差別化
> **おむつは履かない。** おむつは [[characters/tanabe-momoka|田邊 桃香]] の記号であり、あちらは*他者に強制された罰*。柊は*自分で選んだ擬態*であり、主体と動機が正反対に置かれる。
