# 🔄 トライアド構造と各章の役割

本作は、すべてのエピソードおよび作品全体の流れにおいて**「トライアド（誘因・提示・充足）」**という独自の3段階構造を採用しています。

---

## 1. トライアドの3要素

| フェーズ | 役割 | 描写のポイント |
| :--- | :--- | :--- |
| **誘因 (Trigger)** | 不穏な予兆・トラップ | 追い詰められていく心理的タメ、身体の小さな違和感、逃げ場が失われていく感覚。 |
| **提示 (Presentation)** | 決定的破綻・決壊 | 衆人環視や密室での限界到達、身体的尊厳の崩壊、視線の変質。 |
| **充足 (Fulfillment)** | 絶望と受け入れ・適応 | 羞恥の極みと絶望、あるいはすべてを失ったことによる倒錯的な安堵への着地。 |

---

## 2. 短編集全体における各章の機能割り当て

全五章（六エピソード）は、短編集全体としてもこのトライアドサイクルを描きます。

```text
【誘因】第1章「春」
  └── 【提示】第2章「夏」
        └── 【充足と再誘因】第3章「秋」・第4章「冬」
              └── 【最終提示・充足】第5章「再び春（前・後）」
```

* **第1章：春（田邊桃香）｜【誘因の章】**
  * 物語全体の不穏な幕開け。潔癖な女性教師が政治家たちの密室で窮地に立たされる予兆。
* **第2章：夏（金城向日葵）｜【提示の章】**
  * 鮮烈な公然の決壊。若さと光の中で尊厳が公衆の面前（カーテン裏）で破壊される瞬間のピーク。
* **第3章：秋（遠山楓）｜【充足と客観支配の章】**
  * 決壊した後の事後処理。先輩の弱みを握った後輩による冷ややかな支配と視線。
* **第4章：冬（橘柊）｜【自発露出・再演の章】**
  * 「とある少女」の羞恥体験への執着から、遊園地の観覧車待機列という群衆の前へ、
    柊が自ら歩み出て再演する。**視線がないのではなく、視線へ自ら踏み出す唯一の章。**
* **第5章：再び春 前・後編（田邊桃香）｜【最終的な尊厳の死滅と完全適応の章】**
  * 全貌の開示。おむつの暴露を通じて尊厳が完全に死滅し、被支配の安堵へと着地するクライマックス。

---

## 3. 各章がフォーカスする「失禁の局面」

各章は、失禁という同じ出来事の**異なる局面・異なる視点角度**を描く。単なる時系列の
違いではない。

| 章 | フォーカスする局面 | 視点 |
| :--- | :--- | :--- |
| 🌸 春 | 仄めかし（予兆） | — |
| ☀️ 夏 | 具体的不安 → 失禁の場面そのもの | 本人（向日葵） |
| 🍂 秋 | 失禁事後の**客観視点** | 目撃した側（[[characters/takagi/index\|高木圭]]） |
| ❄️ 冬 | 失禁事後の**主観視点** | 漏らした本人（柊） |
| ✨ 再び春 | 失禁がもたらす**長期的な影響**（倒錯・社会的・人間的） | 本人（桃香） |

秋と冬は、単に「秋＝支配・冬＝退行」というテーマの違いだけでなく、**同じ「事後」を
誰の目で見るか**という視点角度の違いとして設計されている。

---

## 4. トライアドの階層構造（フラクタル）

誘因・提示・充足は**必ずこの順で進むが、必ずしも誘因から始まるとは限らない**。
サイクルの途中から始まってもよい。

さらにトライアドは**階層構造**を持つ。誘因という局面の内部にも、提示・充足と同じ
3分割が入れ子になっている。

```text
誘因の誘因 / 誘因の提示 / 誘因の充足
提示の誘因 / 提示の提示 / 提示の充足
充足の誘因 / 充足の提示 / 充足の充足
```

理論上はさらに深く入れ子にできる（例: 充足の提示の充足）が、実用上は2階層
（例: 充足の提示）までを執筆の単位として使うのが現実的。1章＝複数シーンという
構成は、この階層の1レベル分を具体的な場面数へ展開したものと理解する。

> [!tip] 執筆時の指針
> あるシーンや章が「充足」のトーンから始まり「誘因」で終わる、という構成もありうる。
> 章の冒頭だから必ず「誘因」を置く、と機械的に考えないこと。
