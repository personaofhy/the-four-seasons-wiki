# 🎬 煽りスライド様式

旧バージョンの煽りスライド（`seasons.pdf`／2025年12月）から抽出した構造。**画そのものより、この構造の方が資産価値が高い**ため様式として固定する。

---

## 📐 画面の型

```
┌──────────────┬──────────────┐
│              │              │
│    画像      │   黒地に白   │
│   （左）     │   （右）     │
│              │              │
└──────────────┴──────────────┘
```

左に画像、右は**黒地に白文字のみ**。枠は全ページ共通で、**変わるのは寄りの度合いだけ**にする。右の黒は装飾ではなく**語り手の沈黙**として機能させる。

## 🔭 三段寄りの法則

| 段 | 何を映すか | 役割 |
| :--- | :--- | :--- |
| **1. 顔** | ペルソナが保たれている状態 | 落差の基準を提示する |
| **2. 綻び** | 俯いた横顔、握った手、汗 | 崩れの進行 |
| **3. 一点** | **身体の一部か、物だけ** | 決壊。全身も表情も見せない |

**第3段で人物を見せない**のが要点。旧版は最後の1枚を「耳のクローズアップ」だけで成立させていた。見せないことで、見た者の反応の大きさが伝わる。

## 🗣️ 話者の切り替え

1〜2段は**本人の独白**、3段目だけ**第三者の視点**に切り替える。

> 「信じてきた強さが…脆かっただなんて…」（独白）
> 「あの桃香が…耳を赤く燃やしている！」（第三者）

> [!warning] 切り替えには合図を出す
> 旧版は話者が変わるのに書体も色も同じで、**事故に見えた**。第三者パートは書体か色を変えて、意図的だと分かるようにする。

## 🎨 色と生理

赤面は「頬をピンクに」ではなく、**耳と首筋を燃やす**方向で描く。生理反応としての説得力が段違いになる。これは表情パターン5【狼狽・大赤面】の定義とそのまま対応している。

画像側は各章の16色パレットに寄せ、右の黒は共通で保つ。

## ✍️ 書体

> [!warning] 旧版の失敗
> 手書き風フォントが内容の重さに対して緩かった。「脆かっただなんて…」という台詞に字が可愛すぎる。**細い明朝か、荒れた筆致**に置き換える。

---

## 📎 旧版の記録

`seasons.pdf` 全4ページ。3ページ目が2ページ目とテキストが完全に同一という事故がある（作りかけと思われる）。

**2ページ目のポーズが `himawari_expr_blush_base.jpg` の元**であり、現在ControlNetの共通ポーズ参照として使われている。旧版の桃香は黒髪ロング・ぱっつん前髪の学生で、現在の設定（23歳・明るいブラウンのショート・英語教師）とは別人。造形としてはむしろ現在の[[characters/kaede/index|遠山 楓]]に近い。
