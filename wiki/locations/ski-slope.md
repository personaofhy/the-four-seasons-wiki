# 📍 地元のスキー場のナイター

**登場章:** [[chapters/04-winter/index|04-winter]]　／　**決定状態:** `draft`

第4章の舞台（2026-11-04 本案）。柊の地元にある小さなスキー場で、家業や親の勤務先ではない。

図面は非公開の `studio/bijutsu/drawings/ski-slope/`（`sheet.svg`、`site.dxf`、3D 用の `site.json`）。全て架空の仮の値で、作者決定は下のとおり。

---

## 分かっていること

* **ナイター営業中。** 麓まで距離のある上級者向けのコースが開いている。麓は混雑する。
* **ペアリフト1本** — 柊が一人で座り、短い停止中に実行する場所。
* **コース** — 約3kmの本線と、緩い迂回コース。
* **休憩小屋** — リフト降り場。電話を受けるまで連れの女性がいる。
* **林の縁はコースの中腹で、リフトから約100m。**
* **カーブの内側の林の縁** — 上級者向けの急斜面の脇。引っ込んでいて、注意しなければ滑走者には見えない。照明の切れ目。
* **レストハウスの棚** — 柊が鞄を置く。
* **駐車場** — 麓だけ。柊の車がある。

## 時間の見積もり（`draft`）

図面の値（林の縁から麓まで約1,600m、ペアリフト1,400m）と気温-5〜-8℃で計算した。

| 区間 | 時間 | 根拠 |
| :--- | :-: | :--- |
| 男性が麓へ降りる | 4〜6分 | [中級者は平均時速約32km](https://doaj.org/article/2b935686ece744eca0efec1d27afabe2)。不器用さと夜の混雑を足す |
| 棚で鞄を探す | 5〜10分 | 特徴しか聞いていない（推定） |
| リフト待ち | 3〜10分 | ナイターの混雑（推定） |
| リフト | 約12分 | [2m/sで1,245mが約11分](https://www.skiresort.info/ski-resort/courmayeur-checrouit-val-veny/ski-lifts/l97265/)の例から |
| 林の縁まで滑る | 2〜5分 | 上から約1,400m |
| **男性が戻るまでの合計** | **約26〜43分** | |

女性はリフト降り場の休憩小屋にいて電話で呼ばれる。滑るだけなら4〜6分で、電話までの時間を足すと**10〜15分**で着く（推定）。柊が一人の時間と、女性と二人の時間は、それぞれ10〜20分ほどになる。

## 分かっていないこと

* 照明の配置
