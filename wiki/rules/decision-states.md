# 🔒 決定状態（Decision States）規定

各ノートの設定項目が「**作者が確定させたもの**」なのか「**まだ決まっていないもの**」なのかを、機械可読な形で明示するための規定。

このwikiは執筆エージェントと画像生成エージェントの両方が読む。**空欄が「未決定」なのか「書き忘れ」なのか区別できないと、エージェントは勝手に埋めるか、勝手に諦めるかのどちらかをする。**それを防ぐのがこの仕組み。

---

## 🚦 3つの状態

| 状態 | 意味 | エージェントの振る舞い |
| :--- | :--- | :--- |
| **`canon`** | 作者が確定させた設定 | **変更禁止。**他の記述と矛盾していたら**報告のみ**行い、直さない |
| **`draft`** | 埋まっているが未承認 | 変更を提案してよい。**変更したら必ず申告する** |
| **`open`** | 未決定 | 埋めてよい。埋めたら `draft` に落とす（`canon` に昇格させるのは作者だけ） |

**`canon` へ昇格させられるのは人間だけ。** エージェントが自分で書いた内容を `canon` にすることは、いかなる場合も禁止。

---

## 📝 書き方

frontmatter に `decision_default` と `decision_states` を置く。
**全項目を列挙しない。** 既定値からの例外だけを書く。

```yaml
decision_default: canon        # 明示されない項目はすべてこの状態
decision_states:
  underwear_progression: open  # 例外だけを列挙
  agency_shoes: draft
```

本文中で個別に示す場合は、状態を先頭に置く。

```markdown
> [!question] `open` — 夏の情景パレット
> 未定義。決まるまで衣装色は暫定値。
```

## 🎨 プレースホルダー画像の書き方

画像が未生成の枠は、**プレースホルダーを置いたうえで「何を意図した絵なのか」を必ず添える**。空の枠は情報がゼロだが、意図が書かれていれば、それ自体が発注書になる。

```markdown
| ![[placeholder_top.jpg]] |
| `open` — **意図:** 第一ボタンまで留めた襟元のクローズアップ。<br>皺が一本も無いことが分かる角度。潔癖さの視覚的証拠。 |
```

**禁止:** プレースホルダーだけを置いて意図を書かないこと。実画像と並んだとき、どちらが完成でどちらが未着手か見分けがつかなくなる。

### 第4章の「悪意」— 水準と発生源が確定（2026-08-24）

**Lv.2「ふざけ」に確定。** 一人の積極性に周囲が半受動的に従うだけであり、集団として
企図された加害は存在しない。相手は大学生のアルバイトで、相談する場所も悪意を醸成する
時間もないため、**巧妙な計画は書けない。**

あわせて**待機列に罠は存在しない**ことが確定した。旧記述「悪意に晒されピンチに陥り、
群衆の前で自ら排尿する」は誤り。柊を押し出したのは**三度の下方修正**であり、
**悪意が発生するのは楽屋で正体が露見してから**である。
`chapters/04-winter`、`characters/hiiragi`、`locations/ferris-wheel-queue` を修正済み。

### 段階③の核 — 「前提の明示的な破棄」に確定（2026-08-24）

「実は大人である」と全員の前で暴露し、**全員が大人だと認識していることを共有した上で**
脱衣を求める。**物理的に同じ脱衣が、前提が変わっただけで処罰に一変する。**
そして二度目は柊自身の手で脱ぐ。長く `open` だった「半強要される**とある行為**」は、
これによって解消された。

### 段階④の「女性としての最大のタブー」— 確定（2026-08-23）

**マフラーを奪われた後、顔を隠すために上衣を引っ張り上げること。**
下半身はすでに剥き出しであり、彼女は顔以外の全部を晒したまま駐車場を駆け抜ける。
柊にとって**顔は裸より優先される**（アイドル志望として、行為と顔が結びつくのを防ぐため）。

段階③で**課される**タブー（秘部の開陳／下半身剥き出しの楽屋歩行／半強要の撮影）とは
別物である点に注意。**タブーは二重にある。**

### 着ぐるみ — 交代制で確定、ただし「仕組まれたか」は `open`（2026-08-23）

ウサギの着ぐるみの中身は**交代制**であり、小鳥遊が入ることもあるが固定ではない。
小鳥遊の不在中に訪れたウサギの中身は**男性**だった。
**小鳥遊がこれを仕組んだのかどうかは引き続き `open`。**

### 第4章 × 桃香の同期軸 — 「温度」に確定（2026-08-19）

`momoka_sync_theme: ⚠️ 再設計中` を解消。反響の軸は**温度**——
熱に任せた行動と、冷めていく興奮の中の恐怖。桃香は怒りという熱、柊は狂気の行いに走る熱。
**「見る／見られる」は柊の章の内側でしか機能せず、経糸との連結装置には使えない**ことも
あわせて確定した。
