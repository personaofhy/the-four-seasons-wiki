# 📍 向日葵の大学

**登場章:** [[chapters/02-summer/index|02-summer]]　／　**決定状態:** `canon`（2026-11-05 作者決定。寸法は `draft`）

> [!abstract] この場所の役割
> 第2章の全部の舞台を収める校地。博多の市中にある偏差値高めの私立大学で、全体にモダンで緑が多い。規模は大きめの高等学校ほど。**学生は全員18歳以上の成人。**桃香の大学とは別の大学である。

---

## 🗺️ 配置

中庭を4つの棟で囲む、コの字に低い棟を足した形。

| 方位 | 棟 | 内容 |
| :--- | :--- | :--- |
| 東 | **旧校舎** 4階建て | 平成施工、耐震は十分で古びていない。屋上に[[locations/rooftop-pool|プール]]、1階に[[locations/summer-classroom|視聴覚室]] |
| 南 | **新校舎** 8階建て | 高い部分は南へ寄せ、北面は窓なしの壁面緑化。中庭側は3階建ての低層部で、北面はガラスのラウンジ |
| 北 | **北棟** 5階建て | 図書館を含む。5階の南面は窓なしの書庫 |
| 西 | **学食** 1階建て | 屋上緑化。中庭側にテラス |
| 西隣 | 寺町の境内 | 低い屋根と大木。**夕陽はここを越えて中庭へ入る** |
| 南の通り | 正門 | 新校舎のピロティを抜けて中庭へ |

> [!important] 西を低くしているのは夕陽のため
> 学食を2階建てにすると、8月20日の夕陽は17:24で視聴覚室の窓台に届かなくなる。1階建てなら遠景に切られる18:08ごろまで届く。

## 🌳 中庭

| 項目 | 内容 |
| :--- | :--- |
| 緑 | 芝、北寄りに楠の大木、両端の木。**夕陽の帯には木を立てない** |
| 通路 | ピロティから東へ折れて、旧校舎沿いの幅3mの舗装へ。学食のテラスからは石の細道 |
| 窓の前 | 幅3mの舗装とベンチ。地面は窓まで平ら。人はガラスの前まで歩ける |
| 生垣 | ピロティの先に刈り込んだ高い生垣。**中庭の外から窓を見通せない。**裏へ回って初めて窓が見える |

> [!note] 見えるのは中庭の中から
> 生垣が切るのは正門とピロティからの視線だけである。新校舎のラウンジと北棟の窓からは中庭が見下ろせる。

## 🏫 旧校舎の外観と内部

| 項目 | 内容 |
| :--- | :--- |
| 外観 | 明るいタイル。階段室はタイル壁で分け、教室の部分の2階以上に窓と縦ルーバー。1階の窓は視聴覚室と同じ高さの帯 |
| 1階の並び（南から） | 南階段、教室2つ、視聴覚室、準備室、WC、北階段。東側に廊下と諸室 |
| 廊下 | 明色の塩ビ床、温色の木の腰壁、白い壁と天井 |
| 階段ホール | 廊下との境は開け放しで、防火戸は壁の中。中庭へガラス扉で出られる |
| 南階段 | 折り返し階段。走りの間に腰壁（高さ90cm）と木の笠木。**屋上へ出られるのはここだけ。**踊り場に窓はない |

> [!important] 踊り場は両方からは隠れられない
> 1階と2階の間の踊り場では、西側へ寄れば下から隠れるが上から丸見えになる。上下どちらからも隠れる所はない（第2章の10）。上の階の踊り場は未確認。

> [!note] 道すじ
> 屋上から南階段を降り、教室2つの前を通って視聴覚室の前の扉へ。女子トイレは視聴覚室のさらに先にある。走って約40秒の見込み（計算のみ）。
