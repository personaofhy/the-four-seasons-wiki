# 🎯 プロジェクト・ゴールと進め方

本作の**成果物・期日・完成条件**を定義する。何を描くかは [[rules/style-guide|執筆スタイルガイド]]、
どう組むかは [[rules/triad-structure|トライアド構造]] を参照。ここに書くのは「いつ、何が出来ていれば完了か」。

---

## 📦 最終成果物

**漫画作品**（全5章6エピソード）。ただし散文を経由する**二段構成**を取る。

| 段階 | 内容 | 成果物 |
| :--- | :--- | :--- |
| **① 散文プロット** | 「ここでこんなことが起こる」を書き出す。**心理描写も小説風に書く** | 散文 |
| **② 漫画作品化** | ①を踏まえ、**心の声・情景描写・映画的演出**を取り入れて組み上げる | 脚本・作品 |

> [!important] 散文は使い捨てではない
> 段階①は下書きではなく、**心理の解像度を確保するための本番工程**である。
> 漫画化の段で削ぎ落とすことはあっても、最初から粗く書くのは間違い。
> [[rules/style-guide|執筆スタイルガイド]] の散文向けの指示は、段階①にそのまま有効。

段階②の表現手段は三つに分解される。

| 表現手段 | 対応する既存資産 | 状態 |
| :--- | :--- | :--- |
| **心の声**（モノローグ） | 各キャラの `inner_flaw`、感情ビートの設計 | 一部あり |
| **情景描写** | [[rules/color-palettes\|章パレット]]（12〜16色） | 春のみ定義済み |
| **映画的演出**（コマ割り・カメラ・間） | — | **未整備** |

公開先は独自の自作サイトを想定（現行のQuartz Wikiがそれを兼ねるかは未定）。

## 🏁 直近のゴール（〜 2026-09-15）

**1ヶ月以内に、キャラ設定とナラティブなプロットを完成させる。**
本文・画像・3Dはこの期日の対象外。

| # | 完成条件 | 現状 |
| :--- | :--- | :--- |
| 1 | 主人公4人のキャラシートが `status: canon` になる | 0 / 4 |
| 2 | **4人6章の時系列順の出来事がはっきり決まる** | 0 / 6 |

6エピソードの内訳: 第1章春・第2章夏・第3章秋・第4章冬・第5章再び春（前・後）。

②は未着手ではなく**未抽出**。おおよその時系列はすでに構想として存在しており、
それを章ごとに書き出していく作業になる。

①について、`canon` に上げる条件（何が埋まれば確定なのか）はまだ定義されていない。

## 🧭 進め方の原則

### ① 横に広げる。一章だけ先行させない

各章は物語的に独立しており、世界観も混ざらず相互に連関しない（桃香だけが例外）。
それでも、**尿失禁のもたらすホラーとエロスを多角的に描く**という主題において
互いに意識し合う関係にある。加えてトライアド理論上、各章に役割が割り振られている。

**したがって、一章だけ先走って完成させない。** 常に全体のバランスを見る。

### ② 同じ答えを二人に持たせない

「多角的に描く」が設計原理である。4人は同じ破綻を通るが、その意味は重複してはならない。
現在判明している振れ幅:

| 章 | 人物 | 適応形態 |
| :--- | :--- | :--- |
| 🌸 春 | 桃香 | **完全適応**（被支配の安堵） |
| ☀️ 夏 | 向日葵 | 未定 |
| 🍂 秋 | 楓 | **非適応**（耐えたまま消える） |
| ❄️ 冬 | 柊 | 未定 |

春と秋が両端を成している。夏と冬は、この間のどこかに**別の**答えを置く必要がある。

ある章で新しい軸（適応形態、支配の成立機構、感情の順序）が判明したら、
他の3章で同じ軸がどうなるかを必ず確認する。
