# 💧 尿の物理・解剖・繊維

本作の破綻描写を**物理と解剖に接地させる**ための参照ドキュメント。
「どこから出て、何に当たり、どこを通って、どう見えるか」を順に定める。

数値は成人女性の一般的な値。**個体差はあるが、桁は動かない。**

> [!important] このドキュメントの使い方
> **描写のチェックリストであって、描写の指示ではない。**
> ここに書いたことを全部書けば説明過多になる。**ここに反することを書かないため**に使う。
>
> とくに効くのは次の三点。
> - **座位では前方に流れない**（＝立ち上がるまで露見しない）
> - **下着の保持容量は15mL程度**（＝本格的な排尿は1〜2秒で下着を無力化する）
> - **素材で挙動が真逆になる**（綿は吸って広がる／化繊は吸わずに落ちる）

---

## 1. 起点 — 外尿道口の位置と初期ベクトル

**男性のような突出したノズルがない。** これが全ての挙動の前提になる。

- 外尿道口は**腟前庭内**、陰核と腟口の間。恥骨結合の後下方に**引っ込んでいる**
- 尿道長は**3〜4cm**と短く、膀胱頸部から前下方へ向かう軸を持つ
- 開口部が小陰唇に囲まれているため、**小陰唇の形状・癒着状態がそのままノズル形状として働く**。束になって前下方に飛ぶ／二股に割れる／会陰に沿って後方へ這う、という個体差はここで決まる

**つまり射出方向は、解剖ではなく姿勢でほぼ決まる。**

| 姿勢 | 初期ベクトル | 一次到達点 |
| :--- | :--- | :--- |
| **直立・膝伸展** | 前下方。恥骨弓に阻まれ弱い | クロッチ前部内面 |
| **直立・内股** | 下方。大腿内側が壁になる | クロッチ → 左右大腿内側 |
| **椅子座位** | ほぼ真下〜後方 | クロッチ中央 → 会陰 → 臀部と座面の間 |
| **中腰・しゃがみ** | **前方へ飛ぶ** | クロッチ前部を通過して前方へ |

> [!tip] 座位は「立ち上がるまで露見しない」
> 座位で前方に流れないという点は物語的に重要で、
> **「座っている間は本人以外気づかない／立ち上がった瞬間に露見する」**という展開は
> 物理的に正しい。

---

## 2. 第一段階 — 空隙とインパクト

**立位ではクロッチと外尿道口は密着していない。数mm〜1cmの空隙がある。**

最初の一瞬、尿はこの空隙を**飛んで**布の内面に当たる。

このため初期に濡れるのは**布の内面の一点**であり、外側にはまだ何も出ていない。
布が疎水性なら数百ms〜1秒、**外からは完全に無傷に見える時間帯が存在する。**

---

## 3. 素材 — ここが分岐点

繊維の**公定水分率**と**毛細管構造**で、挙動が真逆になる。

| 素材 | 公定水分率 | 挙動 |
| :--- | :--- | :--- |
| **綿（コットン）** | 8.5% | 繊維そのものが膨潤して吸う。染みは接触点から**放射状に円形**に拡大。吸収が速く初期は外に漏れないが、**飽和が早い** |
| **ポリエステル／ナイロン** | 0.4% | 繊維は吸わない。液体は繊維の**隙間**を毛細管で走るだけで保持しない。染みは広がらず**そのまま重力方向に落ちる**。濡れると透過率が変わり、肌に貼り付いて色が濃く見える |
| **レース・メッシュ** | — | 開口率が高く**ほぼ素通り**。受け止め機能なし |
| **シームレス薄手マイクロファイバー** | — | 面で肌に貼り付いているため、液膜が**布と肌の間に閉じ込められて**面状に広がる。布の外に出るまでが遅い |

> [!warning] 化繊ショーツでも、クロッチライナーだけは綿という製品が非常に多い
> つまり**第一の受け皿だけが親水性で、その周囲は疎水性**という不連続な構造になっている。
> 「最初は吸って止まり、溢れた瞬間から一気に落ちる」という二相の挙動は、これで説明できる。

---

## 4. 形状 — 容量と堰

- **クロッチライナー**：おおむね 10cm × 5〜6cm、2枚重ね、150g/m² 前後。布重量は約1.8g。綿の保水量を自重の8倍とすると**保持できるのは15mL程度**
- **ハイレグ／T字**：クロッチ幅2〜4cm。受け止め面積が小さく、**即座に縁から溢れる**
- **ボーイレッグ／ボクサー**：面積が広く、脚口ゴムが大腿を締めているため一時的な**堰**になる。**溜まってから脚口の縁で一気に落ちる**という時間差が生じる
- **縫い目**：ステッチ糸は撚糸で毛細管力が強い。布地の面拡散より**縫い目に沿った線状の濡れが先行する**。折り返し・縫い代部分は布が三重で保水量が高く、**そこが導水路になる**

---

## 5. 量とタイムスケール — 「下着では受け止められない」

**ここが物理的にいちばん重要な帰結。**

| 項目 | 値 |
| :--- | :--- |
| 快適な膀胱容量 | 400〜500mL（強い尿意で600mL以上） |
| 最大尿流率 Qmax | 健常女性で **20〜30 mL/s** |
| 平均尿流率 | 10〜15 mL/s |
| 完全排尿にかかる時間 | 20〜40秒 |
| **下着の保持容量** | **15mL程度** |

**流量15mL/s なら、約1秒で飽和する。**

- **数mL規模の少量漏れ** → 下着内に完全に吸収され、外観上は無変化。**本人しか知らない段階が成立する**
- **本格的な排尿** → 1〜2秒で下着は無力化され、**以降の98%以上は素通りする**

> [!important] 「少し漏れた」と「決壊した」の間には、物理的な断絶がある
> 連続的に悪化するのではない。**下着が意味を持つ領域と、まったく持たない領域は不連続**で、
> その境界は1秒程度で通過する。
> 描写でも、この二つは**別の出来事**として書き分けられる。

---

## 6. 溢れた後の経路

### 立位

1. **クロッチ飽和**（1〜2秒）
2. 会陰に沿って一部が**後方（臀裂）へ回る**
3. 主流は**脚口の縁から大腿内側面へ**
4. 大腿内側は皮膚同士が近接し液膜が保たれるため、**線ではなく面で濡れる**
5. 膝内側 → 下腿 → 足首 → **靴下**（綿なら強く吸う）→ 靴の中
6. 床には初め**滴下**、やがて**連続的な細流**。足元に水たまり

> [!tip] 非対称性
> **体重をかけている側の脚に多く流れる。左右差が出るのが自然。**
> 内股にすると左右の流れが合流して一方に集中する。

### 座位

1. クロッチ → 会陰 → **臀部と座面の間**
2. 敷いている衣服（スカート・ズボン）の**接触面全体**に面拡散
3. **座面に溜まり**、椅子の縁から滴下
4. 立ち上がると**臀部側が広く濡れており、椅子に水たまりが残る**

---

## 7. 外衣の挙動

| 外衣 | 挙動 |
| :--- | :--- |
| **スカート** | 立位では肌から離れているため**内側は基本無傷**。座位では敷いているので座面接触部が濡れる |
| **タイツ／ストッキング** | ナイロンで吸わない。液膜が肌とナイロンの間に閉じ込められ、**脚全体に薄く広がる**。濡れると光沢と色が大きく変わるため**最も目立つ** |
| **デニム** | 300〜400g/m² の厚手綿。保水量が大きく、**股から逆三角形の濃い染み**として染み出す。乾きにくい |
| **淡色チノ・カーキ** | **色差が最大。視認性が最も高い** |
| **ジャージ（ポリエステル）** | 吸わないため、**脚を伝って落ちる量が増える** |

---

## 8. 熱と音

**熱** — 37℃で出て、濡れた布の**蒸発潜熱**で急速に冷える。
**「最初は温かく、すぐに冷たい」は感覚的表現ではなく、蒸発冷却の物理そのもの。**
布が肌に貼り付いている面積が広いほど冷感は強い。

**音** — 布を介するため**飛沫音は減衰する**。代わりに、布を通過した後の**滴下音**と床への
流下音が遅れて立ち上がる。**音源の位置が、体から床へ移動する。**

---

## 9. 断続の物理

外尿道括約筋は**随意筋**である。完全な決壊の前に「漏れる→止める→漏れる」の**断続相**が
入りうる。

この間、**各パルスは数mL単位なので下着に吸収されきる。**
**断続相の長さが、外観上の無変化がどれだけ続くかを決める。**

---

## 10. 章ごとの担当 — 四つの破綻を混ぜない

**各章で見せる物理現象を一つに絞る。** 担当外の現象は書かない。

| 章 | 担当する物理 | 根拠 |
| :--- | :--- | :--- |
| **春（桃香）** | **§9 断続と、§6 座位の溜まり** | 章は決壊の直前で閉じる。**断続相そのものが本体** |
| **夏（向日葵）** | **§6 立位経路（布ゼロ）** | 布が一枚もないので§3〜4が丸ごと存在しない。**跳ねる軌跡と、傾斜を下る流れ** |
| **秋（楓）** | **§3 素材の三層** | レース（素通り）→ ナイロン（吸わない）→ ウール（大量に吸う） |
| **冬（柊）** | **§8 熱（湯気）と蒸発冷却** | **冬だけが視覚で見せる** |

**四人の条件が物理的に一つも被っていない。**

| | 姿勢 | 下着 | レッグ | 外衣 | 床 | 露見 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **桃香** | **椅子座位** | **無地コットン**（吸う） | 浅履き＋腹巻き | ポリ混スラックス（吸わない） | 座面 | **立ち上がるまで起きない。椅子が告発する** |
| **向日葵** | 立位・爪先立ち | **なし** | なし | なし | 傾斜した床 | **湯気で即座に全員へ** |
| **楓** | 立位→走行→崩落 | レース（素通り） | **ナイロン** | **ウール**（大量に吸う） | **タイル（吸わない）** | 背後の目撃者一人 |
| **柊** | **立位と座位の両方** | 児童用綿 | 冬物タイツ | 丈の長いシャツ | 舗装面／座席 | 一度目は公開、**二度目は誰も気づかない** |

> [!tip] 具体的な運用
> 夏で素材の話を始めない（布がない）。秋で湯気を出さない（季節が違う）。
> 春で床への流下を書かない（座っている）。
> **一章一現象に絞ることで、四つの破綻がそれぞれ別の記憶として残る。**

## 11. 章別の経路 — 条件から演繹する

各章の姿勢・素材・環境から、**実際に何が起きるか**を順に追う。

### 🌸 春（桃香）— 座位・綿・合皮

**布は吸い、座面は吸わない。**

1. 椅子座位なので**前方には流れない**（§1）。ほぼ真下〜後方
2. **無地コットンのショーツが吸う**。放射状に広がり、外観は無変化のまま（§3）
3. **保持容量15mLで飽和**。断続相の二回分は、まだここに収まる（§5・§9）
4. 飽和後は会陰を伝って**臀部と座面の間**へ
5. スラックスは**ポリエステル混で吸わない**（§7）→ 座面へ落ちる
6. 合皮のソファは吸わない → **座面に溜まる**

> [!important] 濃色の合皮の上では、液体は色ではなく光の反射で見える
> 黒や焦茶の座面に透明な液体が乗っても、**色差はほぼ出ない。そこだけが光っている。**
> 誰かが気づくとしたら、染みを見つけるのではなく**光り方の違い**に気づく。
>
> そしてソファは**深く沈む**。立ち上がるには一度大きく前へ体重を移す必要があり、
> **合皮なので立つときに音が出る。** 逃げにくく、動けば鳴る。

**露見は最後まで起きない。** 本人は自分の背面を見られないので、**最後に気づくのが本人**。

### ☀️ 夏（向日葵）— 全裸・立位・爪先立ち・ガラスに密着

**布が一枚もないので、§2〜§4が丸ごと存在しない。**

> [!important] 前面が密着しているので、前方へは飛べない — 尿はガラスを伝う
> 立位で身体の前面を窓ガラスに押し付けている以上、**§1の「前下方」ベクトルの先には
> ガラスがある。**
>
> 最初の流れは空中を飛ばず、**ガラスの内側に当たり、そのまま伝って流れ落ちる。**
> つまり**校庭側の野次馬からは、ガラスを流れ落ちる液体がそのまま見える。**
> 布による遅延も、拡散も、吸収も、一つも介在しない——**四人の中で、最も何も隠れない。**

1. ガラスの内側を伝い、**窓枠の桟**（床から145cm）の上に落ちる
2. 桟から**床へ落下する**。**1.45メートルの落差**——音が出る（§8）。
   布を介さないため飛沫音は減衰せず、**音源が身体から床へ、はっきり移動する**
3. 階段状の床なので、**液体は最前列（低い側）へ下っていく**
4. 爪先立ちで両脚が緊張しているため内転筋が締まり、**大腿内側を伝う量は少ない**。
   主流はガラスと桟の側へ行く

**熱** — 夏なので蒸発冷却が効かない。**「すぐに冷たい」が起きない唯一の章。**
温かいまま、肌の上に残り続ける。**冬の柊と正反対。**

**匂い** — 夏の熱気で立ちやすい。そして嗅ぐのは向日葵自身（[[characters/himawari/index|cpt-9e60]]）。

### 🍂 秋（楓）— 三層・立位→走行→崩落・タイル

**素材が三段階で切り替わる、唯一の章。**

| 層 | 素材 | 挙動 | 所要 |
| :--- | :--- | :--- | :--- |
| ショーツ | レース | **ほぼ素通り**（§3） | **0秒** |
| パンティストッキング | ナイロン | **吸わない。液膜が肌とナイロンの間に閉じ込められる** | — |
| ワンピース | マットウール | **大量に吸う。重くなる** | 裾と背面 |

> [!important] パンストが「閉じ込める」のが要点
> ナイロンは吸わないが、**肌に密着しているため液膜が布と肌の間に保たれる**（§3）。
> だから脚を伝う流れが**線ではなく面**になり、**脚全体に薄く広がる。**
>
> そして**濡れたナイロンは光沢と色が大きく変わる**（§7）——**四人の中で最も視覚的に目立つ。**
> 楓だけが、**遠目にも一目で分かる状態**になる。

1. 走りながらの決壊なので、**足元に点々と飛散する**
2. トイレ棟の目前、**タイルの上で本格的な決壊**。タイルは吸わないので**広がって残る**（§6）
3. 膝から崩れる → 姿勢が中腰〜しゃがみに変わる → **§1の「前方へ飛ぶ」に切り替わる**
4. ウールのワンピースが吸って**重くなる**。乾かない

**そして脱衣が物理的に困難になる。** 濡れたパンストは脚に貼り付き、腰から一体なので
**下だけ脱ぐことができない。** 個室での脱衣に時間がかかる理由が、素材から出てくる。

### ❄️ 冬（柊）— 湯気・立位／座位の二度

**同一人物が二つの姿勢でやる、唯一の章。**

**一度目（列の前・立位）**

| 層 | 素材 | 挙動 |
| :--- | :--- | :--- |
| 児童用ショーツ | **綿** | 吸う。1〜2秒で飽和 |
| 冬物タイツ | ナイロン | 吸わない。液膜を閉じ込める |
| オーバーオール | 厚手綿 | **大量に吸う**。股から逆三角形の染み（§7） |
| 丈の長いチェックシャツ | 綿 | しゃがみ込むことで**裾が汚れる**（本人の計算） |

- **湯気が立つ**（§8）。冷気の中で、37℃の液体が布を透過して外気に触れる
- **匂いは立たない**（低温）。**冬だけが視覚で見せる**
- 乾いていく過程で**気化熱が体温を奪い続ける**——濡れている間より、**乾いていく間のほうが冷たい**

**二度目（車内・座位・タオルの上）**

- §6の座位経路。**タオル（綿）が吸うので、座面にはほとんど届かない**
- 車内は暖かいので**湯気は立たない**
- **音だけが残る。** 布が吸う音、体温、座席の沈み——**この章で唯一、音でしか書けない場面**

> [!tip] 一度目と二度目で、可視性が完全に反転する
> 一度目は**湯気で全員に見える**。二度目は**誰にも見えない。**
> 同じ人物の、同じ行為が、環境だけで正反対になる。

---

## 12. 未決の物理条件

- **視聴覚室の床材**（夏）— 木か、リノリウムか。**傾斜を下る速度と、跳ねる音が変わる**
- **オーバーオールの素材**（冬）— デニムか綿ツイルか。**染みの形と乾きにくさが変わる**
- **公用車のシート素材**（秋）— 布なら吸って染み、ビニールレザーなら水たまり。
  **桃香の合皮と被らせないなら布**
- **応接ソファの色**（春）— 黒か焦茶か。どちらでも「光の反射でだけ見える」は成立する
