## 何を集めると決まりが早いか

5部位（輪郭・眉・目・鼻・口）を潰すのが目的。以下が揃うと言語化できる。

| 優先 | 欲しい画 | これで決まるもの |
| :---: | :--- | :--- |
| ★★★ | **正面・無表情** | 輪郭の型、目の間隔、パーツの配置 |
| ★★★ | **目元のアップ** | 二重の幅、目尻の角度、切れ長か丸いか |
| ★★ | **正面・笑顔** | 口角の上がり方、頬の出方、歯を見せるか |
| ★★ | **斜め45度** | 鼻筋の通り方、輪郭の立体、顎の細さ |
| ★ | 髪型（横・後ろ） | 髪型は既に差別化を担っている。補強用 |

**1人あたり3〜5枚で足りる。** 枚数より「正面・無表情」と「目元アップ」が入っているかが効く。

## 決まった後の流れ

1. 選んだ顔から、輪郭・眉・目・鼻・口を**設定書の語彙に翻訳**する
2. `content/characters/<名前>.md` の `## 🎭 顔` テーブルに書き戻す（**各ノートが唯一の正**）
3. `content/characters/index.md` の「4人を分ける軸」表に、顔の差別化行を追加する
4. 4人を横に並べて**見分けテスト**。名前を伏せて判別できなければ差別化が足りていない
