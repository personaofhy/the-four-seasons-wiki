## 1. 前提の寸法

| 項目 | 値 | 出典 |
| :--- | :--- | :--- |
| 向日葵の身長 | 170cm | 人物設定 |
| 足場（窓台） | 外の地面から 85cm。ガラスから 3.5cm 離れて奥行き約 10.5cm | 視聴覚室の寸法 |
| 上の桟 | 外の地面から 265cm。足元から 180cm | 同上 |
| 下がれる量 | かかとが落ちる分（およそ 5〜8cm）＋膝を曲げる分 | 一般的な目安 |

足場が浅いので、腰を前に出すほど足と腰の位置がずれ、桟を引く手への依存が増える。

## 2. どこが当たるか

- 立った姿勢で一番前に出るのは**恥丘**。腰を前に出せば、まずここがガラスに付く
- その下の陰部は体の下側へ回り込むように奥へ向かう。ガラスは垂直なので、**恥丘が支えになって下側は浮きやすい**
- **腰を反らせると骨盤は前に傾き、陰部は下から後ろへ向いてガラスから離れる。** 付けるには、胸は反らせたまま骨盤だけ後ろに傾ける（腰を突き出す）必要がある
- 脚を開く動機は自然にある。太腿が先にガラスに当たるので、腰を近づけるには開くしかない

## 3. 下がっていく時のずれ（中心の仕組み）

**接触面は摩擦で窓に残り、骨格だけが下がる。** だから骨から見ると、接触している組織は上へ引かれる。接触面が上に動くのではない。

![[assets/diagrams/glass-press-shear.png]]

| 段階 | 起きること |
| :--- | :--- |
| 1　潰れて広がる | かかとが高く、接触は高い位置。恥丘が平らに潰れ、周りへ広がる |
| 2　張り付いたまま下がる | 骨だけが下がり、接触面は同じ高さに残る。**接触面より下の組織が上へ引かれて張り、上にはたるみが寄る** |
| 3　限界を超えて滑る | 摩擦が負けて接触面が下へ滑る。組織は少し戻り、通った所に跡が残る |

2と3を繰り返しながら下がる（止まっては滑る）。

- **広がる力と引かれる力は別物。** 左右へ広がるのは押す力で、段階1。上へ引かれるのは段階2で加わる
- **汗で長さが変わる。** 汗が少ないほど張り付いて段階2が長い。汗が増えると摩擦が落ち、急に滑る
- **腰がガラスから離れると引っ張りは止まる。** 桟を掴む腕が伸びきるあたりで起きやすい

## 4. 陰部への影響

| 状態 | 見立て |
| :--- | :--- |
| 大陰唇がガラスに潰れて平らになる | 接触していれば自然 |
| 脚の開きと圧で左右に少し開く | 十分ありえる。個人差が大きい |
| 段階2で下側が上へ引かれ、めくれる | ありえる。**左右に開くより「持ち上がってずれる」動き**になる。量は皮膚の余裕で決まり、数cm以内 |
| 内側まで広く見える | 最も無理がある。押す圧は組織を閉じる向きにも働く |

**陰核：** 本体は靭帯で恥骨とつながり、骨と一緒に下がる。包皮は皮膚なので、段階2で上へ引かれる。逆向きに動くので、**包皮がめくれて先端が出ることは物理的にありえる**。

- 接触が恥丘の上の方だけなら、包皮まで届く力は弱い。接触が下へ広がるほど起きやすい
- 皮膚の余裕を超えるほど下がらないと起きない。かかとの分だけなら軽く、膝が折れて大きく下がると起きやすい
- 段階3で滑ると少し戻る。張り付いている間だけ出て、滑ると隠れる、の繰り返しもありうる
- 包皮の長さや余裕は個人差が大きく、必ず出るとも出ないとも言えない

## 5. 外から分かること

- **見上げの視点は下側を見るのに有利。** ただし、接していない所は脚の間の陰に入る。夕方の順光でも暗い
- 局部に起きる変化は小さく、接触面かそのすぐ下の陰にある。**はっきり見えるより「何かが起きている」程度**
- **胸も同じ動きをする。** 下の皮膚が張り、胸がガラスの上に残るように持ち上がる。局部を書かずに同じ現象を伝えられる
- **ガラスの跡。** 最初の高い接触位置から下へ、汗と皮脂の跡が残る。何が起きたかと時間の経過が外から分かる
- **音。** 滑るたびに、肌とガラスがこすれて鳴る

## 6. 画像生成での知見

- 3D の素体を押し付けて計算した形でも、**濃淡から深度を推定させると平らさが失われた**。Blender から書き出した法線を ControlNet に渡すと、平らな接触面が出た
- ただし接触面の縁が硬貨を貼ったように硬く、なじませるのは未解決
- LoRA `breasts_on_glass` は SD1.5 用。SDXL のモデルとは組めない。強さを上げても形はほとんど変わらなかった
- 除外語では局部の細部を消せなかった
